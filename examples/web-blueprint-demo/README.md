English | [中文](README.zh.md)

The separate [Subagent conformance composition](subagent-completion.cordis.yml) boots real Host plugins for the example-owned keyless snapshot. Its driver owns temporary presets and models an authoring completion event; the production resolver proves delegation delta, a fresh verification Session's P1 result, projection, and one terminal record without a browser timeline, model provider, or business child. It does not use the preview's simulated completion state.

This opt-in overlay previews Blueprint inside the shipped DSH Web interface. It injects fixture data before the production browser plugin graph starts; the Web shell, theme, navigation, conversation UI, Blueprint components, slots, and CSS all remain the built production implementations.

Build the repository once, then start the preview:

```sh
pnpm run build
pnpm run demo:blueprint
```

Open <http://127.0.0.1:3082/?fixture&blueprintDemo>. The `fixture` query selects the keyless browser-memory transport, while `blueprintDemo` authorizes the injected fixture binding and starts after the versioned welcome acknowledgement so the focused preview is not blocked by unrelated first-run UI. Production onboarding remains unchanged. The real preset picker exposes only Creator mode and the demo-owned `上市公司研究 Agent`. New preview sessions start from the real `danger-full-access` permission preset, so the production permission picker displays `Full access`.

The fixed walkthrough uses production conversation and Blueprint components for Agent creation, a three-item Purpose proposal, Skill authoring, collaborator-Agent authoring, approval prompts, and a final NVIDIA trial. Fixture Session events provide the 12–20 second Creator progress, 2–4 second Apply state, capability publication, and 8–15 second trial report. The walkthrough never calls a model, executes Tool implementations, writes Host files, or accesses the network. Its final verification message means only that the deterministic Demo reached the expected local flags; it is not Harness runtime conformance. Use `重置 Demo` to return to the prefilled unsent Creator request.
